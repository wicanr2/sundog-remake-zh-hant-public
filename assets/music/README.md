# 陽犬號 HD 原創配樂

這套音樂為 remake 新作，以老貨船、港口貿易、殖民運補與遠航為題材。原版音效仍由玩家自備磁碟提供。原版是否另有背景音樂未在本工作考證；本套曲目不引用或冒稱原版旋律。

主動機為 D4、A4、C5、E5、B4。暖色合成器描寫船體與引擎，電鋼琴描寫港口與交易，細碎金屬節奏描寫危險。勝利保留繼續運補的責任感，避免全面凱旋式配器。

| 曲目 | 場景 | 音樂設計 |
|---|---|---|
| [自由的契約](title.ogg) | 標題、建角、主選單 | 主動機完整呈現，暖墊底與清晰鍵盤旋律 |
| [老船仍在呼吸](ship.ogg) | 船艙、工程、物資、貨艙、睡眠 | 慢速、稀疏主動機與低頻呼吸 |
| [貨單與霓虹](port.ogg) | 城市、交易、銀行、室內、運輸站 | 切分電鋼琴、輕打擊與流動低音 |
| [異星的風](surface.ogg) | 世界地表探索 | 空曠音色、延長動機與低密度節奏 |
| [星圖之外](flight.ogg) | 導航、航行及航行睡眠 | 柔和分解和弦與穩定引擎脈動 |
| [不要失去這艘船](combat.ogg) | 實際交戰、地面競技場 | 壓縮動機、低音脈衝與節制打擊 |
| [下一趟航行](ending.ogg) | 任務完成、分數結算 | 主動機轉明亮和聲，保留未完的尾聲 |
| [未償的契約](defeat.ogg) | 失敗終局 | 放慢且省略動機終音，降低配器密度 |

配樂預設開啟。F2 的「背景配樂」與 F6 可切換音樂，F7 繼續只控制原版音效。開關跨次啟動保存，與呈現主題分開。音樂只讀取玩家當前可見狀態，不改遊戲存檔、時間、亂數或規則，不以配樂洩漏尚未顯示的遭遇。

來源為本專案撰寫的 [作曲與合成工具](../../tools/compose_hd_music.go)。工具輸出逐音樂譜、標準 MIDI、分層 WAV 中間檔及正式 OGG；`manifest.json` 保存音訊規格、來源與雜湊。合成器自行生成波形與打擊，未使用 SoundFont、取樣庫或生成式音樂服務。音樂、樂譜與合成工具依專案 [RRSAL-1.0](../../LICENSE) 散布。

重建須在 Go 1.25.12／FFmpeg 的專案 Docker 內執行 `go run tools/compose_hd_music.go -out assets/music -work workplace/hd-music-render`。WAV 與分層檔只放工作目錄，正式播放器只讀 OGG。技術檢查不等於實際聆聽，審聽狀態另記工作收據。

[正常玩家驗證工具](../../tools/verify_hd_music_player.py)從真實 schema45 船艙保存載入，接受 `--binary`、`--disk`、`--save`、`--settings` 與新的 `--output`。它核對五語選項、F2 關閉、F6 開啟、跨程序保存偏好，以及沒有原版音效時的實際 ALSA 混音輸出。只在 Docker 執行，來源保持唯讀；此收據證明播放路徑，不取代人耳審聽。

技術與玩家驗證摘要見 [validation.json](validation.json)。人耳審聽及三輪循環疲勞感仍待確認；日英 HD 選項擷取有前綴字形差異，保留為顯示驗證限制。既有 v.1.3.0 發行包與影片保持原樣，此功能目前在來源主線。
