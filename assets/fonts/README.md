# 字型資產

互動原型使用 `NotoSansCJKtc-Regular.otf` 顯示繁體中文與拉丁字母。它是 Noto CJK
Traditional Chinese（臺灣）字型，依其隨附的 SIL Open Font License（OFL）發布；下載來源、
版本與 SHA-256 會記錄在本目錄的 `ASSET-MANIFEST.md`。字型只解決 glyph coverage，不代表
最終像素美術或 UI 排版已核准。

`UKaiTW-SunDogTitleSubset.ttf` 是已退役的「陽犬號中文版」標題字型，只保留供歷史來源與
授權回查；runtime 與正式封包已不再載入或散布它。兩款字型的來源與雜湊仍記在
`ASSET-MANIFEST.md`。
