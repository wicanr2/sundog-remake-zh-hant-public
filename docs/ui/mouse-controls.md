# 純滑鼠操作契約

狀態：CONFORMED-scoped，限重製版輸入可達性與下述抽測。使用者於2026-10-17要求「想辦法 支援全滑鼠」，授權補齊既有鍵盤操作的畫面入口。此為重製版輔助操作，不稱原版Atari ST控制介面。入口為[操作附錄](../manual/remake-controls-zh-Hant.md)。

## 證據與範圍

已證實：`cmd/sundog-ebiten/main.go` 的 `keyAction`、`polledKeys` 與獨立全域輸入構成目前鍵盤可用動作，`step`保留交易、保存及呈現的應用層分派；選碟由`options.go`的`applyDisk`驗證。不依賴新的原版bytes或未證實玩法。

## 輸入與畫面

- 三種呈現、五種語系共用右上角「操作」入口。開啟後提供目前畫面動作與系統分頁；關閉後保留原畫面與原有滑鼠走路、站位、物品點擊。
- 畫面動作從正式鍵盤分派取得，去除重複，不用合成鍵盤事件。點擊直接走相同`step`。終局、睡眠、動畫、初次選碟與呈現各有既有閘門，輔助入口不能繞過。
- 姓名提供拉丁字母、數字、空白、退格、大小寫與確認的螢幕鍵盤。中文等Unicode姓名仍可由實體鍵盤輸入。磁碟瀏覽器可逐層選目錄與`.st`檔，保留Unicode檔名；錯誤顯示，不隱藏選碟失敗。
- 系統提供說明、設定、保存庫、保存、配樂、音效、呈現與退出。保存庫內槽位沿既有點擊；角色屬性、室內方向、零件選購、吃角子老虎、戰術雷射／牽引／拋貨等有具名按鈕。
- 按鈕分頁，文字在視窗解析度繪製。繪製與命中使用同一份幾何，包含縮放與置中黑邊。動作執行後仍停留同畫面時可繼續點，換畫面即關閉操作卡。
- 即時街頭競技場的右鍵由射擊擁有，通用返回不得先截走；逃離／返回由操作卡提供。這依`starena.go`既有右鍵射擊與`ArenaInput.Firing`契約，修正重製版事件分派衝突，不改戰鬥規則或新增原版對拍聲明。
- 操作卡與既有設定／說明卡一致，開著時不把輸入傳到後方；關閉的那一下也不走路或開其他視窗。卡片狀態不進存檔，不消耗RNG或改變遊戲時間。

## 驗收與停止線

檢查全部正式鍵盤動作的滑鼠可達性、五語標籤、三呈現／縮放命中、輸入隔離、初次選碟閘門、終局、睡眠及保存。正常玩家驗證從標題以滑鼠選呈現、新角色／姓名／屬性、船艙、工程、貨艙、導航、地面、保存、退出與載回；特殊分支以真實保存或規則測試補足，逐項記錄，未實跑不稱全流程動態通過。

schema45、既有存檔、原版素材、RRSAL-1.0與發行邊界保持。原版規則與新觸控、搖桿、任意Unicode螢幕輸入法不在本輪。完成的層級是既有功能全滑鼠可操作，不能外推整款原版parity。

## 重跑入口

Linux正常新局從滑鼠選碟、HD選擇、姓名與屬性，到貨艙／工程／導航／物資／地面／角色狀態、保存庫、配樂／音效、退出與重開，零鍵盤事件通過。另有五語×三呈現十五組實圖與1400×900縮放點擊。全部cmd／internal測試及vet通過；Windows只完成編譯，Windows／macOS滑鼠實機未驗。室內／零件購買／吃角子老虎為滑鼠分派與規則測試，不冒稱完整正常GUI流程。

- [正常新局、選碟、保存及重開](../../tools/verify_mouse_player.py)：由CLI指定候選程式、自備磁碟、來源根目錄、測試模型與全新輸出目錄。模型由`cmd/sundog-ebiten/mousecontrols_test.go`的`TestMouseControlsExposeKeyboardActionsAndGeometry`在設定`SUNDOG_MOUSE_MODEL`時匯出，只供測試選擇可見按鈕，不傳給遊戲。
- 同工具的`--resume-fixture`可從前述正常玩家輸出，另驗標題畫面「載入」及沒有保存庫時的單一保存檔回退。這兩路不使用`-load`啟動旗標，也不改寫來源保存。
- [五語與三呈現](../../tools/verify_mouse_locales.py)：使用真實schema45保存及設定的副本，滑鼠循環語系與呈現，另測1400×900置中縮放。兩工具的參數見`--help`，均須在專案Docker工具鏈中執行。
- `cmd/sundog-ebiten/mousecontrols_test.go`另驗全部交易／銀行子頁、三呈現／三尺寸命中、失敗終局與選碟閘門、姓名、室內移動、零件購買、固定亂數計數的吃角子老虎及禁止按住連續交易。單元測試中的特殊畫面狀態不作正常玩家路徑證據。

Docker建置入口為`docker/sundog-remake-build/Dockerfile`，目前映像為`sundog-remake-build:go1.25.12-bookworm-20261014-r1`；詳細命令及本機驗證輸出定位保存於WORKLOG。原版資料唯讀，輸出使用相同UID的可寫目錄；不以主機執行遊戲或腳本。
