# 四語正式語言包覆核（2026-08-31）

## 範圍與來源

- 正式語系：繁體中文 `zh-Hant`、簡體中文 `zh-Hans`、日文 `ja`、英文 `en`。
- 有 `source` 欄位的 Apple II／Atari ST 原版文字，以原版英文為翻譯錨點。
- 重製版新增 UI 以既有繁中語意為翻譯錨點。
- 簡中初稿由隔離 OpenCC `tw2sp` 產生；英、日缺漏由使用者核准的 Google Translate
  網頁產生。Google 只收到玩家可見文字，未收到程式、磁碟映像、圖片或存檔。
- 英文的原版 Apple II 文字與 Atari ST 對話直接保留原文，不以回譯改寫。

## 一次正式 review

初稿完成後執行一次全量覆核。覆核不是只抽看畫面，而是逐份檢查：

1. 四語 UI 與 Apple II catalog 的 key 集合完全相同。
2. `%` 格式參數、對話 `{hh}` 引用集合、對話 block／phrase／line 拓撲不漂移。
3. 英文沒有殘留 CJK，日文對話沒有只剩英文的自然語言項目，所有語言沒有翻譯批次標記。
4. 括號、空字串、重複 key、字型涵蓋與玩家可見溢位另由自動 gate／畫面 smoke 驗證。
5. 逐項修正遊戲語境中的明顯機器誤譯，包括 `SunDog`、cryogenic crew、pilotage、
   scattergun、slot machine、分鐘，以及日文對話五筆引用被誤刪／誤增的句子。

批次翻譯曾發現行首 marker 會被自然語言重排跨越。正式產生器改以每筆獨立 `<x>` 元素，
逐批驗證節點數；失敗時自動二分，單筆才允許依 DOM 原順序收回移到節點外的句尾。舊的
互串初稿已被覆蓋，並以 `nobody_here`／`not_at_booth` 等已知回歸點重新檢查。

通過上述 review 後，十二份檔案標為
`reviewed once; official AI language pack; 2026-08-31`。這個狀態表示翻譯包可進 production，
不把 remake 文案或機器翻譯升格成原版行為證據。
