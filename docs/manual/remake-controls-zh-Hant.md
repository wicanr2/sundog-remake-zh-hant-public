# 陽犬號重製版操作附錄（繁體中文）

來源主線新增：F6 切換 HD 原創配樂，F7 切換原版音效。也可在 F2 選項以方向鍵選擇「HD 背景配樂」，按左右、Enter 或滑鼠切換。音樂偏好保存在 settings.json，與遊戲存檔分開；八首曲目與場景見[配樂說明](../../assets/music/README.md)。既有 v.1.3.0 發行包尚未包含此功能。

本頁只描述目前 `cmd/sundog-ebiten` 與 `cmd/sundog` 重製版的操作，不是原版 Atari ST／
Apple II 控制方式，也不宣稱原版按鍵配置。原版手冊記載 SunDog 主要以滑鼠與 `ACTION`／
`BACK UP` 操作；重製版為了跨平台與鍵盤可測試性，另外提供語意動作鍵。

## 共用操作

到 depot 門口放開滑鼠，或在設施格按 `F`，開啟船艦服務站。`1` 加油、`2` 修船、`3` 買備用油；Banville 另有 `4` 工程服務。購量子頁的 `1` 買滿、`2` 買一單位、`3` 或 `Esc` 結束並返回服務站。`R`／`O` 仍可直接開加油／備用油快捷頁。

工程服務先顯示 FTL 報價，`1` 或 `Enter` 確認，`3`／右鍵／`Esc` 返回。船須停在本城且資金足額，成功後航距由8升9，正銀行優先付款；已安裝時不重複扣款。修船單價依實際船體及星系參數計算。來源與驗證限制見[FTL及depot規格](../atari-st/ftl-boost-spec.md)。

| 操作 | 重製版輸入 | 說明 |
|---|---|---|
| 視窗大小 | `-scale N` | 開啟倍率預設4，視窗1280×800；可拖動邊框縮放。原版圖像採整數倍率，繁中在視窗解析度繪字。Atari ST HD 的圖形與文字直接使用視窗解析度繪製。 |
| Atari ST 原版磁碟 | 初次啟動的選碟畫面；之後也可由 `F2` 選項設定 | 預設開場從玩家自備的合法 Atari ST `sundog.st` 解出原版標題、標誌與製作名單；HD 選項使用獨立重畫。沒有有效磁碟時只顯示選碟畫面，不顯示替代標題，也不能進入遊戲。原版影像不隨重製版散布。 |
| 音效靜音 | `F7` | 開關音效。音效要先用 `sundog-sound-export` 從自己的原版磁碟轉出來；沒轉過的話遊戲本來就是安靜的。 |
| 呈現切換 | `F8` | 依序輪替 Atari ST、Atari ST HD、Apple II，再回 Atari ST。預設 Atari ST；配色、圖塊與版面一起換，不改玩法狀態，偏好會保存。舊 Apple II HD 已退役。 |
| 選項 | `F2`；標題畫面的「選項」列或 `O` | 語系（繁中／簡中／日文／韓文／英文）、呈現預設（Atari ST／Atari ST HD／Apple II）、Atari ST 磁碟路徑。語系立即套用 UI、Apple II 文字與 Atari ST 對話；所有改動寫進 `settings.json`，不寫入遊戲存檔。 |
| 關於 SunDog | 標題畫面 `A` 或視窗第五列 | 製作名單；任一鍵或滑鼠回標題。Atari ST／Apple II 呈現沿原版影像2，HD 呈現使用相同人名的清晰文字與獨立底圖。 |
| 操作說明 | `F1` | 開關全畫面的按鍵說明卡。說明卡開著的時候遊戲不吃其他輸入，`F1` 或 `ESC` 關閉。 |
| 取消／返回 | `ESC`；滑鼠右鍵依畫面而定 | 子畫面返回上一層；**船上與地面**這兩個根畫面開啟角色狀態（原版手冊：沒有可返回的選項時，右鍵顯示角色狀態與持有物品）；說明卡開著時關閉說明卡。地面要回到船上目前用 `ESC`。 |
| 離開 | `F10`；`Q` 在建立角色以外的畫面也可以 | 離開遊戲。建立角色那一頁每一個按鍵都是名字的一部分，`Q` 在那裡不作用（否則叫「Quinn」的角色會在打第一個字母時就把遊戲關掉），空白鍵也只是空白，用 `F10`。**離開前會自動存檔**到可寫入的保存槽——跟 `S` 寫的是同一個檔，下次用 `-load` 啟動就接得回去。在標題／保存庫／建立角色這三個畫面離開不會寫檔，免得用一份空白狀態蓋掉正在玩的存檔。 |
| 滑鼠動作 | 左鍵 | 點擊頁尾動作區；地面畫面點地圖格走一步，**按住不放會朝游標連續走，並且會繞過擋路的格子**。方向鍵按住也一樣。 |
| 存檔 | 依畫面提示的 `S` 或 `Save` | 寫入重製版 JSON 保存檔，不相容原版 Library Disk。離開遊戲時會自動寫同一個檔。 |

## 標題、保存庫與角色

| 畫面 | 輸入 | 動作 |
|---|---|---|
| 標題 | `P`／Enter／Space | 直接開始目前角色。 |
| 標題 | `C` | 開啟角色保存庫。 |
| 標題 | `L` | 載入目前保存槽；沒有保存資料時保留錯誤訊息。 |
| 保存庫 | `N`／Enter／Space | 建立新角色。 |
| 保存庫 | `M` | 建立重製版保存庫 JSON。 |
| 保存庫 | `S`／`L`／`D` | 儲存、載入、刪除目前槽位。 |
| 保存庫 | ←／→ | 切換槽位；畫面顯示「槽位 N」，不顯示內部 `slot-N` 前綴。 |
| 角色建立 | 文字輸入、Backspace、`ENTER` | 輸入與確認 UTF-8 角色名稱。**只有 `ENTER` 確認**——空白鍵是名字裡打得出來的字元，不能同時當結束輸入的按鈕。名字中間可以有空白，開頭的空白會被忽略，結尾的空白在確認時去掉；只有空白的名字不算名字。 |
| 屬性點數 | ↑／↓、←／→、Enter／Space | 五項屬性從 30 開始，共 440 點；上下選擇，左右增減。仍有點數時第一次確認會警告，再次確認可依 Atari ST 原版流程放棄剩餘點數。`Escape` 回到姓名輸入並保留目前分配。滑鼠右鍵等同確認。 |

## 船上與角色狀態

| 畫面 | 輸入 | 動作 |
|---|---|---|
| 船上 | `G` | 前往地面移動。 |
| 船上 | `N` | 開啟導航與目的地選擇。 |
| 船上 | `X` | 開啟戰術畫面。 |
| 船上 | `D` | 發求救信號叫加油船。等待時間依原版計算（在城市 30 分鐘再加一段隨機時間），油箱已滿時拒絕。 |
| 船上 | `E` | 開啟工程艙。 |
| 船上 | `C` | 開啟貨艙。 |
| 船上 | `H` | 開啟角色狀態。 |
| 船上 | **按住**滑鼠左鍵 | Atari ST 版面下艙內有一個小人，**按住左鍵**它才朝游標走，放開就停——原版就是這樣，點一下站位不會直接到達。**放開按鍵的那一刻**如果它站在某個站位裡，才進那個畫面；從站位上方走過去不會誤觸。小人會判牆並繞過擋路的隔間；游標指在站不住的地方就走到最近的可站點。站名只在小人站進該站時顯示。**貨艙走不進去**（原版那個矩形就沒有站得住的位置），用 `C`；同理維修用 `E`。 |
| 船上 | 滑鼠右鍵 | 開啟角色狀態；這對應原版在沒有可返回項目時的 `BACK UP` 行為。 |
| 船上 | `S` | 儲存重製版保存檔。 |
| 角色狀態 | `R`／Enter／Space | 開始休息；再次按鍵請求醒來，強制睡眠須先恢復足夠休息值。 |
| 角色狀態 | `E` | 進食；需要有食物單位。 |
| 角色狀態 | `H` | 手上與身上四格之間搬一件物品（拿起／放下）。 |

## 證據界線

- 以上按鍵是重製版目前的語意輸入契約，已由 reducer／Ebiten smoke test 驗證；不代表
  Apple II 或 Atari ST 原版按鍵。
- `F8` 只證明同一 `State` 的呈現切換與玩法資料不變；目前有 Atari ST／Atari ST HD／Apple II 三個預設。
  Atari ST 的圖塊繪製端已於 2026-08-26 解出（`XMOVEONG:0x0b wmap` 分三條圖形帶、
  由 `GEMBIND:0x1c copy_opaque` 落筆），並與原版實跑逐像素對過。舊 Modern Apple HD 不再是正式選項；新方向見[Atari ST 全畫面HD計畫](../art/atari-st-hd-plan.md)。
- 戰鬥回火、六系統損傷／修理、時間／營養、燃料價格、交易報價與保存格式是重製版資料；
  原版精確公式與 Library Disk 相容性仍保留證據等級，不在本附錄中冒稱 exact。

## 城市地面之下的四個子系統

這四項在 2026-08-21 補上，規則解自原版（見
[`docs/atari-st/city-subsystems.md`](../atari-st/city-subsystems.md)）。

|---|---|---|

| 室內 | `B` | 在卡座旁坐下搭話。 |
| 室內 | `G` | 玩角落那台吃角子老虎。 |
| 室內 | `E` | 走回街上（要站在門口）。 |
| 吃角子老虎 | Space／Enter | 轉一次。注碼由所在星系的物價與治安決定，不能自己改——原版也不行。 |

| 結算（失敗） | `S` 存檔；`Q`／`F10` 離開遊戲 | 失敗是終局，沒有回上一頁的鍵：`ESC`、`F8` 與滑鼠在這一頁全部停用。 |

結算表上那行「無死亡獎勵 25」照原版顯示，但**不計入總分**——原版就是這樣，
`game_score` 沒有把它加進去。

文字版（`cmd/sundog`）的對應指令：地面 `e` 進門；室內 `w`／`a`／`s`／`d` 走、
`c` 櫃檯、`sit` 卡座、`g` 機器、`e` 離開；老虎機 `spin`；鬥毆 `f` 出手、`x` 脫身。
