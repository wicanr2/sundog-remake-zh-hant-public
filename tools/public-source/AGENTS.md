# 公開來源工作規約

先讀 README.md、CONTEXT.md 與 docs/index.md。

- 文件與使用者訊息預設使用繁體中文。
- 建置、測試、抓圖與分析使用 Docker；入口見 docs/build.md。主機只操作 Git、Docker 與檔案編輯。
- 保留原版規則、資料索引、碰撞與存檔契約。已驗證的局部行為不得外推為全款 exact parity。
- 修改規則前先提出可回查證據與 READY 規格，再實作及驗證。未知行為不得猜補。
- 原版磁碟、執行檔、掃描、圖像、音效與私人對拍圖片不得加入 Git 或公開包。
- README 只留穩定入口；目前狀態放 CONTEXT.md，歷程放 WORKLOG.md。
- 公開來源來自獨立快照，沒有私人歷史或舊 tag。禁止推入私人 refs。
- 發行版號使用 v.<主>.<次>.<修訂>-YYYYMMDD；既有 tag 與 Release 不覆寫。
- 授權為 LICENSE 中的 RRSAL-1.0，外部字型另依其附帶授權。
