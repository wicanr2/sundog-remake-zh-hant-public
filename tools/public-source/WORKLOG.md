# 公開來源工作紀錄

## 2026-10-16

依使用者選擇的 B 方案建立獨立公開來源。原私人 repo 保留完整歷史、標籤、Release 與全部截圖。公開 repo 使用全新 Git 根提交。

公開匯出補齊 LICENSE，HD 測試改用內容雜湊相同的正式 typed model。遊戲規則與存檔 schema 未變更。

乾淨公開工作樹在既有 Go 1.25.12 Docker 工具鏈通過 `go test -count=1 ./cmd/... ./internal/...`、`go vet ./cmd/... ./internal/...`、12 項封包測試與 Linux 建置。測試未掛載原版磁碟；需要 `HD_WORLD_DISK` 的檢查明確跳過。

公開編譯產物另以合法原版磁碟唯讀掛載，沿正常標題略過序幕、三呈現切換及設定寫入、選項返回與 F10 退出抽驗通過。此項為啟動抽驗，不取代完整玩家流程。Linux 二進位 SHA-256 為 `f778230b64ddfdf65c204fc161cba0f861d1c6a5ff9333e6233af152c44287d4`，未加入公開 Git。

全部公開檔案的素材類型、清單雜湊與常見憑證格式已檢查。原版對拍圖片、掃描、磁碟與音效未匯出。


## v.1.2.0-20261016 五語版

新增韓文，五語共享文字索引、遊戲規則及schema44；韓文以docs/i18n/ko.tsv為唯一人工來源。公開README提供繁中、日文、韓文與英文。修正HD選項長路徑崩潰及共同footer的硬編中文，完整磁碟路徑與遊戲狀態保留。

既有storage射擊測試補固定種子及完整武器條件，避免自然新局船況造成偶發拒絕；正式遊戲亂數不改。普通Go測試、vet、語系來源／字形及16項封包與公開來源工具測試通過；正常五語選項、日韓英工程與韓文重開已有玩家抽驗。翻譯仍待母語編輯完整校閱。

精訊手冊故事依固定雜湊的原頁視覺核對後改寫，公開來源只保存摘要與文字卡工具，不附原頁。原版音效影片及本機完整版保持本機。
